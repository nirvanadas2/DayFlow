# Dayflow

### Human Resource Management System

Every workday, perfectly aligned.

## Overview

Dayflow is an HRMS (Human Resource Management System) built to digitize and streamline core HR operations such as onboarding, profile management, attendance tracking, leave management, payroll visibility, and approval workflows for both employees and HR/Admins.

Modern HR teams juggle attendance sheets, leave approvals, and payroll records across scattered tools. Dayflow brings all of this into a single, role based platform where:

Employees manage their profile, mark attendance, apply for leave, and view payroll, with read only access where it matters.

Admins and HR Officers manage the entire workforce, approving leave, tracking attendance, and controlling payroll from one dashboard.

## Features

### Authentication and Authorization

* Sign up with Employee ID, Email, Password, and Role (Employee or HR)
* Secure password rules with mandatory email verification
* Sign in with error handling for invalid credentials
* Role based redirection to the correct dashboard

### Dashboards

* Employee Dashboard with quick access cards for Profile, Attendance, Leave Requests, and Logout, plus recent activity and alerts
* Admin / HR Dashboard with employee list, attendance records, leave approvals, and the ability to switch between employee views

### Employee Profile Management

* View personal details, job details, salary structure, documents, and profile picture
* Employees can edit limited fields such as address, phone, and profile picture
* Admins can edit all employee details

### Attendance Management

* Daily and weekly attendance views
* Check in and check out for employees
* Status types: Present, Absent, Half day, Leave
* Employees see only their own records, Admin/HR sees everyone's

### Leave and Time Off Management

* Apply for leave with type (Paid, Sick, Unpaid), date range, and remarks
* Leave status tracking: Pending, Approved, Rejected
* Admin can view, approve or reject, and comment on requests
* Changes reflect instantly in employee records

### Payroll and Salary Management

* Read only payroll view for employees
* Admin can view all payroll data and update salary structures
* Ensures payroll accuracy across the organization

### Additional Capabilities

* Email and notification alerts
* Analytics and reports dashboard, including salary slips and attendance reports

## User Roles

**Admin / HR Officer**: manages employees, approves leave and attendance, views and edits payroll

**Employee**: views personal profile, attendance, applies for leave, views salary details
